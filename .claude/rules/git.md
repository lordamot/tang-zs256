# Git Usage

## Branch Model

| Branch | Purpose                                         |
|--------|-------------------------------------------------|
| `main` | ready working solution                          |
| `feat/<name>` | Feature branches (short kebab-case name) |

## Workflow

Work onto mine branch - allowed.
Never push.
Always ask before commit something.

## Commit Messages

Short imperative subject line, no period. Examples:

```
fix the DOS flip-flop's clock
document the port decode
```

- Keep subject under 72 characters
- No ticket/issue prefix required
- English only

## What Not to Commit

- `/.idea/`, `/.vscode/` - editor state
- `/tools/` - the fetched toolchain, ~7 GB, restored by `make toolchain`;
  the scripts in it are force-added (`git add -f tools/*.py tools/*.sh
  tools/*.patch`) and a new script has to be too
- `/build/`, `/sim/out/`, `/mnano/build/` - build products
  (with `infosource/`, the operator's folder, that is the whole of `.gitignore`)
- Gowin scratch: `tang/impl/gwsynthesis/`, `tang/impl/temp/`, and the
  IDE's rewrites of `tang/impl/zs256_process_config.json`.

## What *is* committed on purpose

- **`bin/tang.fs` and `bin/bl616.bin`** - the two shipped binaries, so a
  user can flash without a toolchain.  They are rebuilt from the tree
  (`make bitstream` copies its result to `bin/` itself once the timing
  gate passes, `make fw` leaves it in `build/fw/` and it is copied on).
- **`tang/impl/pnr/`** - the last place-and-route output, including its
  reports.  `zs256.rpt.txt` is the only record of the resource budget
  and `zs256.log` of the clock warnings.
- **`soft/rom/`** - the ROM images the machine runs (the Scorpion's, the
  ProfROM, General Sound's): nothing is built into the bitstream, they go
  onto the card, and the simulation reads them from here.
- **`tang/build.tcl`** - generated by `tools/gowin_tcl.py` on every
  `make bitstream`; committed so the last build is on record.

## Working tree noise

The tree may show a long list of `mode change 100755 => 100644` entries
under `mnano/u8g2/`.  That is a checkout artefact inherited from UKNC
Nano through PK8000 Nano and Korvet Nano, not work.  Use `git diff
--summary` to tell it from a real edit.
